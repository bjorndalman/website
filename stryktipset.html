Mathematical & System Architecture

Four core algorithms power the predictive pipeline to filter market noise and isolate true expected value.

1. Kalman Matrix Filter

Recursively updates team offensive and defensive latent parameters using xG, goal differentials, and shot metrics while accounting for process noise.

2. Monte Carlo Coupon Sampler

Simulates 100,000 full coupon outcomes to evaluate pool prize distribution dynamics and construct reduced mathematical guarantees (e.g. R288).

3. Shannon Entropy Optimization

Measures public over-betting bias against true mathematical probabilities to maximize sole-winner jackpot probability.

4. Fractional Kelly Sizing

Dynamically scales weekly system cost based on calculated pool EV, protecting bankroll against long-tail variance.
